# Sunny Web Studio portfolio draft

A responsive, buildless portfolio website for Hasnain Ali Mehervi (Sunny). Open `index.html` locally or serve this folder with `python -m http.server 8080`. The five browser demos are included in `demos/`.

The hero artwork is an original illustrative CSS interface concept, not a client screenshot. Project descriptions label personal/prototype work and distinguish existing public source from local improvements awaiting publication. There are no invented clients, testimonials, sales figures, experience years or verified delivery claims.

Check visual layout in a real browser and approve final project copy. This draft has not been published.
