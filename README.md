# Sunny Web Studio portfolio

A responsive, buildless personal portfolio for Hasnain Ali Mehervi (Sunny). Source is published on GitHub; no standalone site deployment was initiated. Open `index.html` or serve the folder with `python -m http.server 8080`.

Seven browser demos are bundled under `demos/`. Calculator and Tables Book logic checks were completed in their source repository; visual browser QA and actual speech operation remain pending. The founder portrait is the original photograph supplied and approved by Hasnain.

The hero is an original CSS interface illustration, not a commissioned client screenshot. Projects are labeled as personal work or prototypes. Five existing project audits are published as draft pull requests; they are not merged production updates. The marketplace repository's existing Vercel integration automatically created previews.

No invented clients, testimonials, sales figures or experience years are included. Pricing and delivery commitments are intentionally absent from this public portfolio until approved. Review mobile/desktop visuals and interactions before deploying the website.
